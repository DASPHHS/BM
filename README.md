# Boodschappen Maatje (GROK)

Persoonlijke tool voor dagelijkse deals + gezonde, eiwitrijke, groenterijke recepten van **Albert Heijn**, **Jumbo** en **Lidl**.

## Wat zit erin?
- Actuele top-deals
- 10 HelloFresh-geïnspireerde recepten per supermarkt
- Totaalprijs + prijs per portie (grote eters)
- Macro's (eiwit / koolhydraten / vet / kcal)
- Focus op actieproducten + goedkope basis

## Structuur
- `recepten/ah.md`
- `recepten/jumbo.md`
- `recepten/lidl.md`
- `deals-vandaag.md`
